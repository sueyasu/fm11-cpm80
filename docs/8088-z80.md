# Experimental 8088 + Z80 target

Build with NASM, asm8080, Python and make: `make image8088` (or
`make image8088-2d`, `make image8088-2hd`). The normal make target
continues to build 6809 images. Both targets use the identical system62.bin
and disk filesystem layout, with different IPL and native server binaries.

The 8088 ROM enters 07C0:0000; the IPL relocates to 0100:0000 and reads
the 6 KiB server slot to physical 10000h. The server runs at 1000:0000
with private stack 1000:2000, cache at physical 12000h, and ES=0 shared
CP/M memory. Requires 128 KiB RAM. It loads the common image at DC00h,
installs JP F200h at Z80 reset address 0000h and hands off via FD05h.
WBOOT reloads 22 sectors, cold boot 26. The mailbox ABI is unchanged.

The FDC/8237 driver and local ANSI console derive from fm11-cpm86
commit 8f094f9708f06368b6eaa8be3b11fa446bd2e1dd (MIT). The ANSI parser is that port's subset, not yet
identical to the extended eight-parameter 6809 parser. Disk cache is
single-cylinder, lazy fill, write-through. No HDD support.

The emulator currently requires shared physical RAM between the 8088
and Z80 cards and FD05 arbitration with 8088 as the primary CPU. Verify
these before boot testing. This experimental target has not been
boot-tested.
