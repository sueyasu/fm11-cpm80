# Shared 8086 ANSI console

The 6809 implementation in fm11-cpm80 (m6809/ansi_console.inc at
93bfb0419f9e6e92f189e4da08832c97c4d07bdf) is the behavioral reference.
The NASM include is vendored byte-for-byte in the two repositories:

- fm11-cpm80: i8086/ansi_console.inc
- fm11-cpm86: src/cbios_ansi.inc

Update both copies together; no cross-repository checkout is required
to build either project. Run `cmp` on the two includes to check parity.

The parser accepts up to eight CSI parameters (each saturates at 255);
overlong sequences and private modes are ignored. SGR, tab/form-feed,
right-margin erase and reset behavior match the 6809 implementation.
The native output hook returns CF on failure. The parser stops the
current operation, clears its state and returns CF=1 while preserving
registers and other flags. The public CP/M console ABI is unchanged:
CP/M-80 uses mailbox status; CP/M-86 has no standard CONOUT error result.

Optional isolated execution test (NASM and Python unicorn required):
`python3 tests/test_ansi8086.py`. The stub records native bytes and
injects a transport error; it does not test the display hardware.
